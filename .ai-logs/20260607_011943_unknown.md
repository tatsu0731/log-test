## 🎯 目的（やりたいこと）

* インターン生の**GitHub Copilotのプロンプト（AIへの指示）を可視化**し、FB（フィードバック）を行いたい。
* インターン生に手動コピペなどの**作業負担（手間）を一切かけたくない**。
* **特定のリポジトリに関するチャット履歴だけ**を絞り込んで収集したい。

## 🛠️ 解決策（システム構成）

* **全自動の収集（Git Hook）**
* `git commit` 時に裏でスクリプト（`pre-commit`）を自動実行する。
* VS Codeのローカルデータベースから、該当リポジトリのチャット履歴（指示とAIの回答）だけを自動抽出してリポジトリ内に保存する。


* **ログデータの明確さ**
* **誰のログか:** Gitのコミット作成者情報と直結するため、GitHub上で100%特定可能。
* **会話の区別:** 「ユーザーの指示」と「AIの回答」が分かれたタイムライン形式で記録される。


* **PR（プルリク）のノイズ対策**
* `.gitattributes` ファイルを設定し、GitHubのPR画面ではログファイルの差分を自動で折りたたむ（非表示にする）。
* これにより、通常のコードレビューの邪魔にならない。



## 🏃‍♂️ 今後の進め方

1. **スクリプトの配置:** リポジトリ内に `.hooks/pre-commit` と `.gitattributes` を作成してプッシュする。
2. **インターン生の設定:** 各自のPCで `git config core.hooksPath .hooks` を1回だけ実行してもらう。
3. **運用の開始:** 自動で蓄積されるログを見ながら、1on1などでプロンプトのFBを行う。

## 各ツールの抽出ロジック

| ツール | データ保存場所 | リポジトリ絞り込み方法 |
|---|---|---|
| **GitHub Copilot Chat** | `~/Library/Application Support/Code/User/workspaceStorage/<hash>/chatSessions/*.json` | `workspace.json`のフォルダパスで照合 |
| **Claude CLI** | `~/.claude/projects/<path-hash>/*.jsonl` | プロジェクトハッシュ（パスの`/`を`-`置換）で特定 |
| **OpenAI Codex** | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` | `session_meta.payload.cwd`で照合 |

---

## インターン生への設定手順（1回だけ）

```bash
# リポジトリをcloneした後、一度だけ実行
git config core.hooksPath .hooks
```

これ以降、`git commit`するたびに自動でログが `.ai-logs/YYYYMMDD_HHMMSS_<名前>.md` として保存され、コミットに含まれます。

## 注意点

- **VS Code起動中でも動作**: SQLiteをコピーしてからread-onlyで読むため、ロック問題を回避しています
- **ログ収集の範囲**: 「前回のコミット以降」のメッセージのみ（初回コミット時は過去24時間）
- **スクリプトが失敗してもコミットはブロックしない**: エラー時は警告を出してスキップ
- **Copilotのレスポンス**: 現在はMarkdownテキスト部分のみ抽出（コードブロックはファイルパスのみ記録されるため未取得）
